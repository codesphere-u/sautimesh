# Contributing to SautiMesh

We welcome community contributions—especially regional language lexicon packs, anonymized code-switching evaluation cases, and open speech model adapters (`Sunbird Sunflower v2`, `USOAL`, `Masakhane`, `Lelapa InkubaLM`, `Piper`, `whisper.cpp`).

1. Fork and branch from `main`.
2. Run tests locally with `pytest -v`.
3. Keep core modules dependency-free on Python `3.11+` stdlib so Termux and edge hardware never break.

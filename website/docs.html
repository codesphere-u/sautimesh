Getting Started

Install & Setup

v0.1.0

Install Python Package (3.11+)

Runs 100% offline on Python 3.11+ stdlib across Linux, macOS, Raspberry Pi & Android Termux. 

pip install -e git+https://github.com/codesphere-u/sautimesh.git#egg=sautimesh

First Voice Turn

Run your first mixed-language turn cleanly offline with automatic SMS/USSD packing and SQLite WAL persistence:

sautimesh chat --text "Ssebo obuwuka bungi mu kasooli farm yange leero" --currency UGX

ASR, TTS & Ollama Cascade

SautiMesh pairs pure-Python 16 kHz PCM VAD with clean CLI/HTTP protocols for regional open weights:

  • Sunbird AI Sunflower v2 / Gemma Edge: Open weights for 67 African languages via Ollama or GGUF endpoints.
  • whisper.cpp / faster-whisper / Meta MMS: Swap ExternalCommandASR when native binaries are present.
  • Piper ONNX / USOAL Luganda TTS: Plug local ONNX voices into PiperCommandTTS.

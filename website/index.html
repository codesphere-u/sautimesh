questions

How does SautiMesh handle intermittent connectivity and power dropouts?

Every turn executes offline-first playbooks using SQLite WAL persistence and an idempotent store-and-forward outbox queue, syncing safely without split-brain corruption when cellular service returns.

Which African and global languages does SautiMesh support?

SautiMesh ships built-in lexicons and code-switch analyzers for Swahili, Luganda, Yoruba, Hausa, French, English, Nigerian Pidgin, and Runyankole, plus adapters for Sunbird Sunflower v2, whisper.cpp, MMS, and Piper ONNX.

How does SautiMesh prevent runaway cloud API costs?

Its 3-stage cascade resolves routine turns locally in 0 ms, supports local SLMs via Ollama or llama.cpp, redacts phone numbers and PINs before cloud calls, and enforces daily local-currency spend limits.

# Security & Privacy Policy

SautiMesh handles voice transcripts that may include sensitive clinical symptoms, financial account mentions, phone numbers, or national identifiers.

- **Local PII Redaction**: Phone numbers, PIN/OTP tokens, and ID numbers are redacted before remote SLM or cloud escalation.
- **No Unbounded Network Calls**: HTTP requests enforce strict timeouts and local-currency FX budget limits.
- Report security issues privately via `codesphereinnovationz@gmail.com`.
